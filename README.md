# No Grass Under Buildings

Performance-focused rewrite for Satisfactory 1.2.4 (CL 502094) and SML 3.12.

The mod hides landscape grass and small decorative foliage beneath foundations
and buildings, including foliage on cliffs. Vegetation returns when the
covering buildable is dismantled.

This beta replaces the previous implementation with targeted exclusion boxes
and event-driven reconciliation. It contains no save persistence, permanent
foliage removal, or continuous diagnostic logging.
