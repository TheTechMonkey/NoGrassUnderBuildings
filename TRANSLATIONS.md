# Translations

No Grass Under Buildings currently includes:

- English (`en`)
- German (`de`)
- French (`fr`)
- Spanish (`es`)
- Brazilian Portuguese (`pt-BR`)
- Polish (`pl`)
- Russian (`ru`)
- Simplified Chinese (`zh-Hans`)
- Japanese (`ja`)
- Korean (`ko`)

The first translations were machine-assisted and reviewed for consistent meaning, but native-speaker corrections are welcome.

Translation source files are under `Content/Localization/NoGrassUnderBuildings/<culture>/NoGrassUnderBuildings.po`. Keep each `msgctxt` and `msgid` unchanged and edit only its `msgstr`. The compiled `.locres` files are generated by Unreal Engine from those PO files.

Diagnostic console commands and log output remain in English. The player-facing mod name, description, setting names, and tooltips are localized.
