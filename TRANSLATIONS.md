# Translations

No Grass Under Buildings currently includes:

- English (`en`)
- German (`de`)
- French (`fr`)
- Spanish (`es`)
- Brazilian Portuguese (`pt-BR`)
- Polish (`pl`)
- Russian (`ru`)
- Simplified Chinese (`zh-Hans`)
- Japanese (`ja`)
- Korean (`ko`)
- Traditional Chinese (`zh-Hant`)
- Italian (`it`)
- Ukrainian (`uk`)
- Bulgarian (`bg`)
- Czech (`cs`)
- Dutch (`nl`)
- Arabic (`ar`)
- Esperanto (`eo`)
- Finnish (`fi`)
- Hungarian (`hu`)
- Latvian (`lv`)
- Norwegian (`no`)
- Romanian (`ro`)
- Serbian, Cyrillic (`sr-Cyrl`)
- Thai (`th`)
- Turkish (`tr`)
- Vietnamese (`vi`)
- Farsi (`fa`)

Australian, Canadian, and UK English use Unreal Engine's fallback to the native English (`en`) resource.

The first translations were machine-assisted and reviewed for consistent meaning, but native-speaker corrections are welcome.

Translation source files are under `Content/Localization/NoGrassUnderBuildings/<culture>/NoGrassUnderBuildings.po`. Keep each `msgctxt` and `msgid` unchanged and edit only its `msgstr`. The compiled `.locres` files are generated by Unreal Engine from those PO files.

Diagnostic console commands and log output remain in English. The configuration-page name, description, setting names, and tooltips are localized. The separate Mods-page name and description come from raw plugin descriptor strings; SML does not currently localize that metadata, so they remain in English.
